## Steps

1. Open Settings, then select Users & Roles.
2. Select Create User.
3. Enter the username and create the user.
4. Share the one-time invite link with the user so they can set their password.
5. Open the user detail page to assign roles such as viewer, stats-editor, or stats-editor-approver.
6. Grant access to the namespaces the user should work in.

> Users need both the correct role and namespace access before they can work in namespace-specific areas.
