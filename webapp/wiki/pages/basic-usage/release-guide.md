## Steps

Publishing a release will generate the files to distribute with the latest changes included

1. Open Releases
2. Create a release and choose the change types to include
3. Review the release overview, included changes and notes
4. Move the release to review when it is ready to generate artifacts for validation
5. Publishing the release will deliver the artifacts to any consumesr (currently none configured)


## Release artifacts

- CDB SQLite file
- rider stats in a standalone sql file for FirstCycling
- a release overview HTML file (should we change to pdf?)
