## Steps

Riders can be selected for editing by selecting a race result or creating a rider list

1. Open Stats Editor.
2. Use race results or stat lists to find riders that need updates.
3. Enter stat changes for the riders.
4. Save changes once finalized
5. Approvers can approve the changes to commit the new stats to the database

## Discord Integration

If configured a new discord thread will be started once changes are saved alerting approvers of the submitted changes.

## Edits for Multi-Day Races

Tours and multi-day races are not edited per-stage but only once at the completion of the tour.
