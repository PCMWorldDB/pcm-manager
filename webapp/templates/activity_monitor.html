Activity overview

{% if selected_namespace %}

Activity Monitor brings together race-result evidence from ProCyclingStats and FirstCycling to show recorded rider activity and checks that may need review. {% if monitor_summary %}Imported history and checks carried out in PCM Manager are shown separately below.{% endif %}

A saved result confirms that a rider raced. A check is flagged for review when rider details do not match or a profile cannot be confirmed.

How to use Activity Monitor
  1. Open Riders to find riders, check their status, and review saved activity.
  2. Select riders there and choose Start checks to review the selection on Run checks before confirming it. The manual check panel starts up to 25 riders at a time.
  3. Open a rider to review source checks, the PCS profile, and saved race evidence.
  4. Use Review to find website checks and profile details that need a closer look.

Automatic checks run only when enabled in Run checks.
